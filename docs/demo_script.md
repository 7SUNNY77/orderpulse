# OrderPulse v1.0 — сценарий демонстрации (2–3 минуты)

Это сценарий, видео не записано. Перед показом: `python -m orderpulse app`, браузер на http://localhost:8501.
Числа в репликах — из артефактов релиза: `topk_dev.csv`, `metrics.json`, страница «Качество».

| 0:20–0:35 | График «Доля задержек по месяцам» | «Уровень задержек сильно скачет: всплески в конце 2017 и в феврале–марте 2018. Это важно для оценки модели.» |
